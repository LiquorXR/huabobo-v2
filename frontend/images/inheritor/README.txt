胶东花饽饽非遗传承人头像（模块②）
================================

将头像图片放入本目录，按下列文件名放置即可自动显示。
未上传时显示默认人物图标占位。

命名规则：inheritor-{区县ID}-{序号}.jpg
- 区县 ID 与地图 data-district 一致
- 序号为该区县传承人列表中的顺序，从 1 开始
- 推荐尺寸：200×200px 或更大正方形，JPG/PNG/WebP 均可（.jpg 为默认扩展名）

当前各区县默认文件名（每区 1 位传承人）：

  inheritor-zhifu-1.jpg      芝罘区
  inheritor-fushan-1.jpg     福山区
  inheritor-laishan-1.jpg    莱山区
  inheritor-muping-1.jpg     牟平区
  inheritor-penglai-1.jpg    蓬莱区
  inheritor-longkou-1.jpg    龙口市
  inheritor-laizhou-1.jpg    莱州市
  inheritor-zhaoyuan-1.jpg   招远市
  inheritor-qixia-1.jpg      栖霞市
  inheritor-laiyang-1.jpg    莱阳市
  inheritor-haiyang-1.jpg    海阳市

若某区县有第二位传承人，使用 inheritor-zhifu-2.jpg 等。
也可在 js/huayang-yantai.js 对应条目中设置 avatar: 'images/inheritor/自定义文件名.png'。
