人生时间轴照片（模块③ huayang.html）
================================

将图片放入本目录 images/timeline/，按下列文件名放置即可自动显示。
未上传时显示占位图标。支持 .jpg / .jpeg / .png / .webp（默认先找 .jpg）。

时间节点照片（点击节点后，在下方介绍卡片中显示）

  node-birth.jpg       出生
  node-wedding.jpg     结婚
  node-longevity.jpg   寿宴
  node-qiaoqian.jpg    乔迁
  node-spring.jpg      春节
  node-qingming.jpg    清明
  node-duanwu.jpg      端午
  node-qixi.jpg        七夕

建议尺寸：正方形约 400×400px，花饽饽或场景特写。

也可在 js/huayang-timeline.js 对应节点中设置 photo: 'images/timeline/自定义名.png'。
